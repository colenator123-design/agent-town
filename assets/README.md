# Optional local character skins

The public repository does not distribute third-party character artwork or animations.
Agent Town works with built-in text and procedural fallbacks when these files are absent.

For a private, local installation, users may provide artwork they are legally allowed to use under these optional filenames:

```text
pikachu.png
pikachu-animated.gif
dragonite.png
dragonite-animated.gif
porygon.png
porygon-animated.gif
meloetta.png
meloetta-animated.gif
```

Static images should be transparent PNG files. Animated images should be transparent GIF files. These local files are ignored by Git.

`agent-town-v2.png` and `agent-town.png` are original generated town backgrounds included with the project.
